**Sonic Runners Revival for PS Vita — Release 0.1 is here!**

I've tested this release across most of the game's available flows. It includes **Vita button controls**, **reduced race stutters**, and updated **LiveArea and splash artwork**.

**Download the VPK:** https://github.com/ggdrn/SSR-VITA/releases/download/0.1/SRR-Vita-v0.01.00.vpk
**Get the game APK:** https://sonicrunners.com/#/download

Install the VPK with VitaShell and place the APK at `ux0:data/srr/srr224.apk`. **kubridge.skprx** and **libshacccg.suprx** are required.

**Game data downloads automatically and is saved locally — those files only need to be downloaded once.** Downloads may occasionally fail; if that happens, **close the game and reopen it to retry**.

**Controls:** X = jump/tap · Square = item · Triangle = switch character · L / Start = pause/back.

**Known limitations:**
- Startup, connecting to the server, and some menus can be slow.
- Initial downloads can fail intermittently.
- Frame rate varies; constant 60 FPS is not guaranteed.
- Some characters or materials may still have visual glitches.

Thanks to the **Sonic Runners Revival team** and everyone behind the Vita homebrew tools used by this port!
