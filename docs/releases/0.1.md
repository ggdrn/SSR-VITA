# Sonic Runners Revival for PS Vita — Release 0.1

Tested by the maintainer across most of the game's available flows.

## Download and setup

- **VPK:** [SRR-Vita-v0.01.00.vpk](https://github.com/ggdrn/SSR-VITA/releases/download/0.1/SRR-Vita-v0.01.00.vpk)
- **Game APK:** [Sonic Runners Revival download](https://sonicrunners.com/#/download). Copy it to `ux0:data/srr/srr224.apk`.
- Requires **kubridge.skprx** and **libshacccg.suprx**. Install the VPK with VitaShell.

**Game data downloads automatically and is saved locally.** These files only need to be downloaded once. If a download fails, close the game and reopen it to retry.

## Highlights

- Vita button controls: **X** to jump/tap, **Square** to use an item, **Triangle** to switch character, and **L / Start** to pause/go back.
- Reduced race stutters, UI copy optimizations, and thread-lifetime fixes for longer sessions.
- Updated LiveArea and splash artwork.

## Known limitations

- Startup, server connection, and some menu transitions can be slow.
- Initial data downloads may fail intermittently; restart the game to retry.
- Frame rate varies by scene; a constant 60 FPS is not guaranteed.
- Some characters or materials may still show visual glitches.

VPK filename version: **0.01.00**. Vita application version: **00.10**.
